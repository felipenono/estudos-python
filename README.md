# 🐍 Estudos em Python

Este repositório é o meu laboratório de aprendizado contínuo em Python. Aqui documento minha evolução, resoluções de exercícios, desafios de lógica e pequenos scripts de automação.

## 🎯 Objetivo
Consolidar os fundamentos da linguagem (lógica, estruturas de dados e POO) e criar uma base sólida para projetos maiores de back-end e análise de dados.

## 🗂️ Organização do Repositório
Os arquivos estão divididos por pastas para facilitar a navegação:
*   📁 `01-logica-e-controle`: Estruturas condicionais (if/elif/else) e laços de repetição (for/while).
*   📁 `02-estruturas-de-dados`: Exercícios com listas, tuplas, dicionários e conjuntos.
*   📁 `03-funcoes-e-modulos`: Criação de funções, tratamento de erros e importação de bibliotecas.
*   📁 `04-projetos-praticos`: Pequenos sistemas (ex: calculadoras, automação de arquivos) para aplicar o conhecimento.
